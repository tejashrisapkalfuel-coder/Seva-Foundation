## 🚀 GitHub Pages द्वारे वेबसाइट मोफत लाइव्ह करण्याची पद्धत (Step-by-Step GitHub Pages Launching Guide)

वेबसाइट ऑनलाइन करण्यासाठी तुमच्याकडे १ रुपयाही खर्च न करता **GitHub Pages** चा वापर कसा करावा, याची सोपी ५ मिनिटांची स्टेप्स खालीलप्रमाणे आहे:

### पायरी १: GitHub खाते (Account) तयार करा
1. [github.com](https://github.com/) वर जा आणि विनामूल्य खाते तयार करा (उदा. `tejashri-sapkal` किंवा `seva-foundation-ngo`).

### पायरी २: नवीन Repository (प्रकल्प दालन) तयार करा
1. GitHub वर लॉगिन केल्यानंतर वरच्या उजव्या कोपऱ्यातील **`+`** चिन्हावर क्लिक करा आणि **`New repository`** निवडा.
2. Repository Name मध्ये `seva-foundation` टाईप करा.
3. **`Public`** पर्याय सिलेक्ट ठेवा आणि **`Create repository`** बटणावर क्लिक करा.

### पायरी ३: वेबसाइट फाईल्स अपलोड करा
1. तयार झालेल्या नवीन Repository च्या पानावर **`uploading an existing file`** या लिंकवर क्लिक करा.
2. तुमच्या कॉम्प्युटरमधील `seva-foundation` फोल्डरमधील खालील फाईल्स ड्रग अँड ड्रॉप करून अपलोड करा:
   - `index.html`
   - `css/styles.css`
   - `js/main.js`
3. खाली **`Commit changes`** बटणावर क्लिक करा.

### पायरी ४: GitHub Pages सुरू करा (Enable Hosting)
1. Repository च्या वरील **`Settings`** (सेटिंग्ज) टॅबवर जा.
2. डाव्या बाजूच्या मेनूमधून **`Pages`** पर्यायावर क्लिक करा.
3. **Build and deployment** विभागात:
   - **Branch**: `main` (किंवा `master`) निवडा.
   - **Folder**: `/ (root)` निवडा.
4. **Save** वर क्लिक करा.
